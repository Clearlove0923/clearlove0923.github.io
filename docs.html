系统要求

操作系统Windows 10 / 11，基于 x64
运行库官方安装包已包含 .NET 与 Windows App SDK 运行库，无需单独安装
Steam 客户端需已安装并可正常登录
游戏库Steam 游戏库内需已入库对应游戏
游戏本体本地已安装国服游戏本体（无需国际服）

一键更新是怎么工作的

已有配置可在预设区域点击「一键更新」，助手会重新获取元数据。

候选沿用与切换

  • 优先沿用当前仍有效的 Depot 与占位 EXE。
  • 当前候选失效时，只在剩余候选唯一的情况下自动切换。
  • 存在多个有效候选时，仍需手动选择后重试，避免按返回顺序误写配置。

备份策略

  • 内容发生变化时，原 ACF 会备份到软件安装目录的 backups\<AppID>。
  • 每个 AppID 最多保留最近 2 份备份，最长保留 30 天。
  • 内容相同则不产生新的备份。
  • 安装器会为该目录设置普通用户写入权限，避免因权限不足导致备份失败。

根据 AppID 自动填充

在自定义页面填写 AppID，点击「自动获取游戏信息」，即可通过 steamcmd.net 获取以下信息：

  • 显示名称（优先使用页面所选语言）
  • 安装目录（保留 Steam 登记值）
  • Steam 占位 EXE
  • DepotID
  • 公开分支的 BuildID / Manifest

仍需手动处理的部分

  • 真实游戏 EXE / 启动器位置需要你在本地选择。
  • 出现多个 Depot 或启动 EXE 时，需要在候选列表中选择；同一个 EXE 的不同启动参数会合并展示。
  • 选择 Depot 时会同步对应的 Manifest。

结果处理

  • 唯一候选会直接填入。
  • 网络失败或缺失字段会保留原值并标明未验证。
  • 请求期间修改输入、切换语言、切换预设或离开页面，会丢弃过期结果。
  • 获取操作不会直接写入 Steam 文件；配置保存继续沿用现有按钮，以及离开页面时的自动保存流程。

已知限制与注意事项

多 Depot 限制：当前 ACF 仍只支持一个 Depot。多个 Depot 可能需要共同使用，请核对后再选择。

  • 自动填充功能不保证生成完整的安装配置，生成后请自行核对关键字段。
  • DepotID / Manifest 等元数据以 steamcmd.net 的公开数据为准，官方调整后需要重新获取或一键更新。
  • 本工具不提供游戏本体下载，也不改动国服客户端的更新机制。
  • 请在遵守游戏与平台相关用户协议的前提下使用。
