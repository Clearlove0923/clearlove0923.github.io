普通游戏可直接使用助手提供的三种启动方式。只有官方启动链较特殊时，才需要本页参数或桥接程序；实际文件路径请以本机安装目录为准。

首次使用桥接器前，请通过官方启动器完成登录、更新并成功进入一次游戏。推荐将启动器与游戏本体放在同一个总目录下。

桥接 EXE 下载后无需重命名：放到对应游戏的安装目录，再到软件的游戏配置界面选择该桥接 EXE 作为可执行文件。

绝区零

如需启用 DirectX 12，可在对应游戏配置的启动参数中填写：

-use-d3d12

鸣潮

可按需要组合以下参数：

-d3d11强制使用 DirectX 11
-SkipSplash跳过库洛图标等开场展示，直接进入漂泊者选择界面
-krqlv=uhd使用高清材质包

异环

下载 NevernessToEvernessLaunchBridge v1.1（CNB 下载 EXE / GitHub 下载 EXE / 发布说明），保持文件名 NevernessToEvernessLaunchBridge_v1.1.exe 不变，放到包含官方启动器与游戏本体的安装根目录或其子目录，在软件的游戏配置界面将该桥接 EXE 选择为可执行文件，不覆盖官方文件。

  • 首次运行前通过官方启动器完成登录和更新；运行桥接器时按提示接受 UAC。在官方启动器中勾选 DX11 使用 DirectX 11，取消勾选使用默认 DirectX 12；桥接器沿用官方设置。
  • v1.1 保留英文报错并追加中文排查提示；等待资源检查超时后恢复官方启动器窗口，请在该窗口完成更新后重试。
  • 再次双击会结束安装目录内已确认身份的旧桥接器并重新接管，包括旧版错误弹窗；不结束游戏、官方启动器或更新任务。请同步修改旧版快捷方式。
  • 游戏已运行时继续跟踪，不重复启动；此时退出游戏后不强制清理旧启动器。安装范围外的旧桥接器须手动退出。
  • 自动测试覆盖异常窗口恢复、旧进程结束及接管；用户反馈窗口恢复符合预期。登录、语音、反作弊、游戏运行中接管与 Steam 连续在线状态尚未完成本次逐项实机复测。
  • 日志位于 EXE 同级 NevernessToEvernessLaunchBridge-log/NevernessToEvernessLaunchBridge.log，保留最近七天；可选 INI 与详细验证边界见发布说明及源码文档。

明日方舟：终末地

下载 ArknightsEndfieldLaunchBridge v1.0（CNB 下载 EXE / GitHub 下载 EXE / 发布说明）。保持文件名 ArknightsEndfieldLaunchBridge_v1.0.exe 不变，将它放在游戏安装目录内；不要覆盖官方启动器或游戏 EXE。

  • 首次使用前，请先通过官方鹰角启动器完成登录和更新。在软件的游戏配置界面，将桥接 EXE 选择为可执行文件；运行时按提示接受 UAC。
  • 图形模式沿用官方启动器设置；需要 DX11 时在官方启动器勾选对应选项。桥接器不提供独立 DX11/DX12 参数，未勾选时使用官方默认 DX12 模式。

燕云十六声

下载 WhereWindsMeetLaunchBridge v1.4（CNB 下载 / GitHub 下载），保持文件名 WhereWindsMeetLaunchBridge_v1.4.exe 不变。桥接器可放在游戏安装目录树中的任意常规位置，不必与 launcher.exe 同级；不要覆盖官方的 launcher.exe 或 yysls.exe。

以下可选参数填写到软件游戏配置的“特殊启动参数”中。首次使用前请先通过官方启动器成功进入一次游戏。

  • --attach-only：只跟踪已经启动或随后由官方启动器启动的游戏，不主动启动本体，默认最多等待 180 秒。
  • --startup-timeout-seconds N：附着模式等待游戏出现的最长时间，范围 1–1800 秒。
  • --exit-delay-seconds N：游戏进程消失后的延时退出时间，范围 0–300 秒，默认 10 秒。
  • --install-root "安装根目录"：显式指定安装根目录，默认从桥接 EXE 所在目录向上查找。
  • --variant Win64r 或 --variant Win64rh：指定直启本体目录，默认优先 Win64r，再尝试 Win64rh。
  • --dry-run：只输出识别到的目录和启动命令，不启动游戏，适合先检查配置。
  • --no-dialog：出错时不弹窗。
  • 在软件的游戏配置界面，将 WhereWindsMeetLaunchBridge_v1.4.exe 选择为可执行文件。

选择 DirectX 11 或 DirectX 12

请先在官方启动器中选择所需模式并成功进入一次游戏，之后通过桥接器启动会沿用该设置：

  • DX11：勾选“使用 DirectX 11 启动”，再通过官方启动器成功进入一次游戏。
  • DX12：取消勾选“使用 DirectX 11 启动”，再通过官方启动器成功进入一次游戏。

无限暖暖

下载 InfinityNikkiLaunchBridge v1.1（CNB 下载 / GitHub 下载），保持文件名 InfinityNikkiLaunchBridge_v1.1.exe 不变，直接放在游戏安装根目录，再在软件的游戏配置界面将它选择为可执行文件。

运行时按提示接受 UAC。如需指定图形接口，在“特殊启动参数”中填写 --dx11（或 --d3d11）或 --dx12（或 --d3d12），两者不能同时使用；不填写时使用默认模式。

卡拉彼丘

首次使用前，至少通过对应渠道的官方启动器成功进入游戏一次。下载 CalabiyauLaunchBridge v1.3（CNB 下载 / GitHub 下载），保持文件名 CalabiyauLaunchBridge_v1.3.exe 不变，放到游戏安装目录内任意常规位置；不要覆盖官方 CalabiYau.exe。

  • 运行时按提示接受 UAC，无需点击官方启动器的“开始游戏”。
  • 在软件的游戏配置界面，将 CalabiyauLaunchBridge_v1.3.exe 选择为可执行文件。

如需切换 DX11 或 DX12，请先在官方启动器中修改设置并成功进入游戏一次，再使用桥接器启动。

游戏更新后的检查

  1. 先用官方启动器更新并启动一次确认游戏本体和登录流程正常。
  2. 检查游戏配置确认选择的桥接 EXE 仍在原位。
  3. 验证 Steam 跟踪进入游戏后检查运行状态、时长与覆盖层。
