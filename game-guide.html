普通游戏可直接使用助手提供的三种启动方式。只有官方启动链较特殊时，才需要本页参数或桥接程序；实际文件路径请以本机安装目录为准。

本页所用桥接程序由 GameLaunchBridges 单独维护，主程序及其更新由 SteamCN-GameLauncher 仓库维护。桥接 EXE 下载后无需重命名：将它放到对应游戏的安装目录，再到软件的游戏配置界面选择该桥接 EXE 作为可执行文件即可。

绝区零

如需启用 DirectX 12，可在对应游戏配置的启动参数中填写：

-use-d3d12

鸣潮

可按需要组合以下参数：

-d3d11强制使用 DirectX 11
-SkipSplash跳过库洛图标等开场展示

异环

如需让官方启动器静默运行并自动启动游戏，可尝试：

/autoplay

启动器版本更新后，该参数是否仍有效需要重新验证。

明日方舟：终末地

下载 ArknightsEndfieldLaunchBridge v1.0（CNB 下载 EXE / GitHub 下载 EXE / 发布说明）。保持文件名 ArknightsEndfieldLaunchBridge_v1.0.exe 不变，将它放在游戏安装目录内；不要覆盖官方启动器或游戏 EXE。

  • 首次使用前，请先通过官方鹰角启动器完成登录和更新。在软件的游戏配置界面，将桥接 EXE 选择为可执行文件；运行时按提示接受 UAC。
  • 桥接器自动识别安装位置，等待官方启动器检查完成后启动游戏；后台隐藏启动器主窗口，保留官方托盘图标。
  • 游戏退出后默认等待 10 秒，再关闭官方启动器，桥接器随之退出。需要登录或更新等人工操作时，会恢复官方界面并提示。
  • 图形模式沿用官方启动器设置；需要 DX11 时在官方启动器勾选对应选项。桥接器不提供独立 DX11/DX12 参数，未勾选时使用官方默认模式。
  • C++20 原生 Windows x64 单文件，无需安装 .NET 或额外 VC++ 运行库。可选 INI 配置及使用细节见桥接器文档。
  • 日志位于 EXE 同级的 ArknightsEndfieldLaunchBridge-log 文件夹，使用一个主要日志文件，保留最近 7 天记录。

2026-10-15 用户实机确认 C++ v1.0 启动正常，47 项原生回归及产物检查通过。C++ 版托盘与退出清理的逐项完整复测未另行记录，历史原型已验证相应行为；Steam 状态与时长、语音及其他渠道仍待验证。启动器主窗口可能短暂闪现，官方更新后需重新检查启动链。

燕云十六声

下载 WhereWindsMeetLaunchBridge v1.4（CNB 下载 / GitHub 下载），保持文件名 WhereWindsMeetLaunchBridge_v1.4.exe 不变。桥接器可放在游戏安装目录树中的任意常规位置，不必与 launcher.exe 同级；不要覆盖官方的 launcher.exe 或 yysls.exe。

  • 默认会查找 Win64r 或 Win64rh 下的真实游戏进程，并在游戏退出后再结束桥接进程。
  • --attach-only：只跟踪已经启动或随后由官方启动器启动的游戏，不主动启动本体。
  • --dry-run：只输出识别到的目录和启动命令，不启动游戏，适合先检查配置。
  • --no-dialog：出错时不弹窗，诊断信息仍写入日志。
  • 无法识别、缺少值或值无效的参数会被自动忽略并记录到同级日志，便于确认软件或 Steam 实际传入的内容。
  • 在软件的游戏配置界面，将 WhereWindsMeetLaunchBridge_v1.4.exe 选择为可执行文件。

选择 DirectX 11 或 DirectX 12

桥接器负责拉起游戏本体，不会修改官方 DX 配置。请先在官方启动器中选择所需模式并成功进入一次游戏，之后通过桥接器启动会沿用该设置：

  • DX11：勾选“使用 DirectX 11 启动”，再通过官方启动器成功进入一次游戏。
  • DX12：取消勾选“使用 DirectX 11 启动”，再通过官方启动器成功进入一次游戏。

2026-10-14 标准版实机确认：勾选后官方配置保存为 DX12=false，游戏加载 d3d11.dll，随后从 Steam 启动桥接器仍沿用 DX11；取消勾选后配置恢复为 DX12=true。Steam 尾随命令中出现的 DX 控制参数由桥接器忽略并写入日志，实际模式以官方启动器已经保存的设置为准。

完整参数见软件源码仓库中的 游戏特殊启动设置。

无限暖暖

下载 InfinityNikkiLaunchBridge v1.1（CNB 下载 / GitHub 下载），保持文件名 InfinityNikkiLaunchBridge_v1.1.exe 不变，直接放在游戏安装根目录，再在软件的游戏配置界面将它选择为可执行文件。桥接程序会启动 xstarter.exe -skiplauncher，等待真实游戏进程出现，并在游戏退出后再结束自身。

-skiplauncher

桥接程序不改变 Steam 在线状态；它通过保持稳定的启动生命周期，让 Steam 能持续跟踪对应 AppID 的运行状态与时长。

卡拉彼丘

首次使用前，至少通过对应渠道的官方启动器成功进入游戏一次。下载 CalabiyauLaunchBridge v1.1（CNB 下载 / GitHub 下载），保持文件名 CalabiyauLaunchBridge_v1.1.exe 不变，直接放到官方 CalabiYau.exe 所在的安装根目录。

  • 运行时可能出现一次 UAC 提示；桥接器会在后台初始化官方 SDK，然后直接启动游戏，无需点击“开始游戏”。
  • 官方启动器主窗口会持续隐藏，右下角托盘图标会保留；游戏本体连续退出 3 秒后，桥接器会关闭由它启动的官方入口并退出。
  • 在软件的游戏配置界面，将 CalabiyauLaunchBridge_v1.1.exe 选择为可执行文件。
  • 日志位于桥接器同级的 CalabiyauLaunchBridge-log 文件夹。

标准版与腾讯版均已完成真实启动和退出生命周期验证。如需切换 DX11 或 DX12，请先在官方启动器中修改设置并成功进入游戏一次，桥接器会沿用最近一次官方成功启动记录。官方启动链发生变化时，应先用官方启动器更新并成功进入一次，再重新测试桥接器。

游戏更新后的检查

  1. 先用官方启动器更新并启动一次确认游戏本体和登录流程正常。
  2. 检查路径与文件名确认真实 EXE、工作目录和桥接程序仍在原位。
  3. 重新验证参数官方启动器可能改变命令行、环境变量、登录令牌或反作弊初始化流程。
  4. 验证 Steam 跟踪进入游戏后检查运行状态、时长与覆盖层；自动化检查不能替代真实启动验证。
