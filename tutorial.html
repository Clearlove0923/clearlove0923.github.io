使用教程

从下载安装到选择启动方式，再到时长与截图管理，按顺序走一遍即可。

本教程根据小黑盒原帖《一个软件让你在Steam或者本地管理所有二游》整理，配图来自原帖。截图中的路径、账号与游戏数据仅作演示，请使用自己的实际配置。

一、准备工作

开始前请确认以下几项已就绪：

  • Windows 10 / 11（x64）操作系统
  • 如需使用 Steam 启动方式，已安装 Steam 客户端并正常登录
  • 如需使用 Steam 启动方式，游戏库内已入库对应游戏
  • 国服游戏本体已安装在本地，并通过官方启动器完成更新、登录、进入游戏与正常退出至少一次

官方安装包已包含 .NET 与 Windows App SDK 运行库，无需另行下载安装。

只需要本地管理与时长记录时，启动方式选择「国服」即可。使用 Steam 模式前，必须先将对应游戏加入当前 Steam 账号的游戏库。

二、安装助手

  1. 下载安装包在首页点击「下载安装包」，保存到本地。
  2. 运行安装程序双击安装包，按向导提示完成安装。
  3. 打开助手首次打开时建议保持 Steam 处于运行状态，便于读取库信息。

仍安装在 Program Files 的 v3.0.0 以前用户，请先卸载旧版再安装新版；游戏配置与自定义 Manifest 等设置文件会保留。

三、配置全局 Steam 信息

使用 Steam 启动方式时，先进入助手的「设置」，确认以下三项。仅使用本地「国服」模式时可跳过本节。

  1. Steam 安装路径使用「自动检测」或手动浏览，选择包含 steam.exe 的安装目录。
  2. Steam 游戏库路径选择包含 steamapps 子目录的游戏库根目录。有多个库时，请核对是否为你希望存放安装记录的库。
  3. Steam ID（SteamID64）填写当前登录账号的 SteamID64，可在 Steam 的账户明细中查看。

四、添加游戏（两种方式）

方式 A：使用预设（推荐新手）

  1. 进入预设区域在助手中选择你要配置的游戏。
  2. 等待元数据读取助手会自动带出该游戏的常用配置。
  3. 确认本地路径检查游戏安装目录与启动器位置是否正确。

方式 B：填入 AppID 自动获取

  1. 进入自定义页面切换到自定义配置页面。
  2. 填写 AppID输入该游戏在 Steam 上的 AppID。
  3. 点击「自动获取游戏信息」助手通过 steamcmd.net 获取显示名称、安装目录、Steam 占位 EXE、DepotID 以及公开分支的 BuildID / Manifest。
  4. 处理候选列表唯一候选会直接填入；出现多个 Depot 或启动 EXE 时，在候选列表中选择（同一个 EXE 的不同启动参数会合并展示）。选择 Depot 时会同步对应 Manifest。
  5. 手动选择真实启动器真实游戏 EXE / 启动器位置仍需你在本地选择。

AppID 可在 Steam 游戏的「属性 → 更新」中查看。原帖以明日方舟：终末地的 4732690 为例；配置其他游戏时请填写对应的 AppID。若自动获取失败，先检查网络连接后重试。

当前 ACF 只支持一个 Depot。若出现多个 Depot，请核对后选择，必要时参考文档中的已知限制。

五、选择游戏可执行文件与桥接程序

能直接运行的游戏，应选择游戏本体 EXE，而不是仅用于打开官方启动器的 EXE。可先双击候选文件，确认能否正常进入游戏；也可在游戏运行时通过任务管理器定位实际游戏进程。官方启动器路径可另外填入「游戏启动器（可选）」，便于后续更新游戏。

燕云十六声、无限暖暖、卡拉彼丘等启动链较特殊的游戏需要使用对应的桥接 EXE。具体适用游戏和最新下载链接见游戏适配指南。

  1. 下载对应桥接程序从游戏适配指南提供的 CNB 或 GitHub 链接下载当前版本。
  2. 放入游戏安装目录保持桥接 EXE 下载后的文件名不变，直接放到对应游戏的安装目录；不要覆盖游戏官方 EXE。
  3. 选择桥接 EXE回到软件的游戏配置界面，将刚才放入安装目录的桥接 EXE 选择为可执行文件。
  4. 保存并测试保存游戏配置后从软件启动一次，确认游戏与桥接进程能正常启动，并在退出游戏后正常结束。

桥接 EXE 无需重命名。部分游戏首次使用前需要先通过官方启动器成功进入游戏一次，请以游戏适配指南中的对应说明为准。

六、生成配置并设置 Steam 启动选项

先保存配置并选择启动方式。选择「国服」时，可以直接从助手首页启动并记录本地时长；选择「Steam 玩国服」时，继续完成下面的 Steam 配置。

  1. 保存配置点击保存按钮；离开页面时也会自动保存。
  2. 选择启动方式为当前游戏选择“国服”“Steam 玩国服”或“Steam 玩国际服”。
  3. 生成 Steam 配置文件使用「Steam 玩国服」时，点击页面底部「生成配置文件（appmanifest_<AppID>.acf）」，按提示生成并替换配置，然后重启 Steam，确认库中的按钮变为「开始游戏」。
  4. 复制启动命令点击「复制启动命令到剪贴板」，在 Steam 库中右键对应游戏，打开「属性 → 通用」，将完整命令粘贴到「启动选项」。保留助手生成的引号和 %command%。
  5. 从首页启动助手会按保存的方式启动；Steam 模式也可回到 Steam 库启动。
  6. 验证运行状态确认真实游戏进程启动，并在统计页面查看本次会话。
  7. 验证 Steam 功能使用 Steam 模式时，进入游戏后检查覆盖层与好友状态；实际可用性取决于游戏兼容性。

DX11、DX12 与其他启动设置

需要特殊启动参数时，请查阅游戏适配指南。原帖中的终末地桥接示例沿用官方启动器的图形设置：需要 DX11 时在官方启动器中勾选「DX11 启动」，无需再给桥接器添加同类参数。

七、管理截图

  1. 打开“截图”页面从侧边栏进入截图管理。
  2. 选择当前游戏的目录点击「更改文件夹」，可选择游戏自带截图、显卡截图或其他图片目录；每款游戏的路径会独立保存。
  3. 浏览与筛选按日期分组或通过日历跳转，可切换最新或最早优先；没有截图的日期无法跳转。双击图片可放大预览。
  4. 管理文件右键缩略图或大图，可在资源管理器中定位，或将图片移入 Windows 回收站。

八、设置外观

进入「外观」页面，启用自定义背景后点击「导入图片」。可导入多张图片并随时切换，按喜好调整显示方式、不透明度等参数；首页动画与资讯栏也可单独控制显示。

九、游戏与软件更新

Steam 的「开始游戏」变成了「更新」

Steam 侧更新与国服更新并不同步。先在助手中更新 Steam 配置，或重新生成配置文件并按提示替换，然后重启 Steam。国服游戏文件仍通过官方启动器更新。

若已误点 Steam 的「更新」并开始下载国际服文件，先停止下载，核对 Steam 安装目录与国服目录后清理误下载的内容，再重新配置；避免误删国服游戏文件。

国服游戏发布新版本

点击助手中的「打开游戏启动器」，通过官方启动器完成国服更新。更新完成后，再更新或重新生成 Steam 配置并重启 Steam。

更新游戏配置

游戏本体或 Steam 侧数据变化后，可在预设区域点击「一键更新」：

  • 助手重新获取元数据，优先沿用当前仍有效的 Depot 和占位 EXE
  • 当前候选失效且剩余候选唯一时，自动切换
  • 存在多个有效候选时，需手动选择后重试
  • 内容变化时原 ACF 备份到安装目录下的 backups\<AppID>

更详细的策略说明见 文档：一键更新是怎么工作的。

更新软件

发现新版本时，助手会先展示更新说明。确认后可使用默认 CNB 来源下载，也可在设置中切换到 GitHub；下载与校验完成前不会执行更新包。
